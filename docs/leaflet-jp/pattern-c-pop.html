2つの取引スタイル

締め取引一般企業

  • 20日締め・末日締めなど、締め日ごとに1か月分をまとめて請求
  • 入金は締め単位でまとめて消込
  • 複数の得意先を1枚の請求書にまとめる「請求集約」もOK

都度取引官公庁・学校など

  • 納品1件〜数件ごとに明細請求書を発行（すぐ出す・後でまとめる、どちらもOK）
  • 入金は明細（伝票）単位で消込
  • クラス・先生など、宛名を都度指定できる

ここが安心！

  • 消費税もバッチリ　得意先ごとの税区分・端数区分で正しく計算
  • 締めたら守る　確定した伝票は編集不可。解除は管理者だけ
  • 同時編集もへっちゃら　複数の端末からの更新の食い違いを防止
  • 権限でメニュー切替　社員ごとに使える機能を設定
  • 印刷・PDFもかんたん　納品書・請求書・元帳をA4で出力

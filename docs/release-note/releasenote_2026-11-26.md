# リリースノート 2026-11-26

開発期間: 2026-11-18 〜

## 新機能

1. **コピー機マスタのExcel取込**
   「システム管理」に「コピー機マスタExcel取込」画面を追加しました（権限9の利用者のみ）。登録テンプレート（`コピー機マスタ登録テンプレート.xlsx`）に機番・得意先コード・備考を入力して取り込めます。
   - 未登録の機番は新規登録します。登録済みの機番は、得意先コードと備考をExcelの値で上書きします（無効化済みの機番は有効に戻ります）。
   - 得意先コードが得意先マスタに無い行や、無効化済みの得意先の行はエラーとして取り込みません。
2. **得意先別の単価・掛率のExcel取込**
   「システム管理」に「得意先／商品／単価・掛率マスタExcel取込」画面を追加しました（権限9の利用者のみ）。登録テンプレート（`単価掛率マスタ登録テンプレート.xlsx`）に、1行ごとに得意先コード・商品コード・単価・掛率を入力して、まとめて登録できます。
   - 値を入れた単価・掛率だけを追加・上書きします。空欄の項目は変更しません（0 は値として登録されます）。
   - Excelからは無効化できません。無効化するときは「得意先／商品／単価・掛率マスタ」画面で行ってください。
3. **仕入先マスタのExcel取込**
   「システム管理」に「仕入先マスタExcel取込」画面を追加しました（権限9の利用者のみ）。登録テンプレート（`仕入先マスタ登録テンプレート.xlsx`）に、仕入先マスタ画面と同じ10項目を入力して取り込めます。
   - 未登録の仕入先コードは新規登録します。登録済みの仕入先コードは全項目をExcelの値で上書きします（空欄の項目は空になります。無効化済みの仕入先は有効に戻ります）。

3つの取込画面の使い方は共通です。

- 「ファイル選択」またはドラッグ＆ドロップでファイルを読み込むと、全行のプレビューに新規・更新・エラーの区分と、エラーの理由が表示されます。
- 「取込実行」で、エラー以外の行を取り込みます。途中で失敗した場合は1件も反映されません。
- Excelでファイルを開いたままでも読み込めます。

## 機能改善

1. **売上入力・受注入力の明細に定価を表示**
   明細の原価と金額の間に「定価」列を追加し、商品マスタの定価（税抜）を参考として表示するようにしました。伝票には保存されません。列が増えた分、画面の幅を広げました。
2. **納品書の印字位置を右へ移動**
   左端にパンチ穴のある用紙で穴と印字が重ならないよう、納品書全体の印字位置を約5mm右へずらしました。列の幅は変わりません。
3. **操作マニュアルの拡充**
   「得意先／商品／単価・掛率マスタ」と「仕入先／商品／原価マスタ」のページに、設定例と、受注入力・売上入力での表示のされ方を実際の画面で説明する内容を追加しました。単価が決まる順番や端数処理、主仕入先による原価の入り方も説明しています。

# リリースノート 2026-11-05

開発期間: 2026-10-15 〜

## 新機能

1. **納品書の一括発行**
   納品書が未発行の売上を一覧で確認し、まとめて連続印刷できるようになりました。伝票日付や得意先コードで即座に絞り込めます。得意先コードは「...」ボタンから検索して選べます。
2. **得意先別の単価・定価掛率の登録**
   「得意先／商品／単価・掛率マスタ」画面で、得意先を選ぶと商品が一覧に並び、得意先ごとの単価と定価に対する掛率をまとめて入力・保存できるようになりました。未保存の変更があるまま得意先を変えたり画面を閉じたりする場合は確認が出ます。
3. **単価の自動決定**
   受注入力・売上入力・商品検索で、単価が「得意先別単価 → 定価掛率 → 商品マスタの単価」の順に自動で決まるようになりました。内税明細単位の得意先では、税込額に換算して端数処理した単価になります。
4. **商品マスタにJANコード・定価を追加**
   商品にJANコードと定価（税抜）を登録できるようになりました。JANコードは商品検索の対象にもなり、バーコード番号から商品を探せます。
5. **売上・粗利分析**
   メニューに「分析」分類が加わり、「売上・粗利分析」画面で年月を指定して、担当者別・得意先別・商品別の売上と粗利を、タブを切り替えて確認できるようになりました。
   - 列見出しのクリックで並べ替え（初期は粗利の大きい順）
   - 表示している順のままCSV保存
   - 売上額は月次締めの売上額と同じ定義のため、合計は月次締めと一致します
6. **得意先元帳のプレビュー・印刷**
   得意先元帳を、他の帳票と同じくプレビューで確認してから印刷できるようになりました。
7. **請求締めの個別指定**
   請求締めの「締確定」ダイアログで、締日を指定する方法に加え、得意先を個別に指定して締められるようになりました。得意先は検索から追加し、×で除外できます。
8. **明細の商品名の上書き**
   商品を選んだあとで、明細の商品名を手入力で書き換えられるようになりました。書き換えた商品名には末尾に「.」が付き、マスタの名称と区別できます。
9. **操作マニュアルとヘルプボタン**
   初めての方向けの操作マニュアル（日本語・英語）を追加しました。メインメニューの「ヘルプ」ボタンから開けます。
10. **汎用クエリ実行画面**
    マスタ管理に、あらかじめ設定ファイルに登録したクエリを選んで実行し、結果の表示とCSV保存ができる画面を追加しました（権限9の利用者のみ）。

## 機能改善

1. **コピー機売上CSV取込**
   - CSVファイルを画面へドラッグ＆ドロップして読み込めるようになりました。
   - 内税・明細単位の得意先のデータも取り込めるようになりました。
2. **請求締め・月次締め画面の使いやすさ向上**
   - 請求締め・締め解除・月次締め・月次締め解除で、年を入力すると、その年の締め済みの日付・年月から選べるようになりました。
   - 月次締めも「月次締め確定」ダイアログで年月を選んで実行する形になりました。
   - 年月欄の「年」「集計年月」などのラベルを外し、月は数字のみの表示にしました。
3. **登録画面の操作ボタンをファンクションキー形式に統一**
   売上入力・受注入力・入金入力・明細入金の画面で、ボタンを画面下部のF1〜F12の横並びにまとめました。前伝票（F5）・次伝票（F6）・複写（F7）にもキーが割り当てられ、キーボードで操作できます。
4. **メインメニューをタイル型に変更**
   カテゴリごとのカードに全項目を常時表示するタイル型になり、開閉やスクロールなしで目的のメニューを探せます。ウィンドウを狭めると縦1列でも使えます。「自社情報」は「システム管理」へ移動しました。
5. **帳票のページ表記を統一**
   納品書・請求書・明細請求書・得意先元帳・売掛金残高一覧表のページ表記を「（n/N）」にそろえました。
6. **売上日付の入力チェックを追加**
   売上日付が、紐づく受注の受注日より前になる登録・訂正をできないようにしました（同日は可）。売上入力画面では保存前にメッセージが出ます。
7. **受注の中止前に確認を表示**
   中止（F8）は元に戻せないため、実行前に確認ダイアログが出るようになりました。
8. **請求単位の得意先の消費税額が参考値であることを表示**
   売上入力・受注入力で、請求単位の得意先のときは消費税の合計に「（参考）」と表示します。税額は請求締め時に再計算されます。
9. **一覧の見やすさ向上**
   得意先元帳とコピー機売上CSV取込の一覧を1行おきに薄いグレーにしました。検索ダイアログの単価・金額列は見出しごと右詰めにしました。
10. **自社情報に設立年月日を追加**
    自社情報画面で設立年月日を登録できるようになりました。

## バグフィックス

1. **返品・値引の数量が正のまま保存される不具合を修正**
   区分（返品・値引）を先に選んでから数量を入力すると、数量・金額がプラスのまま保存され、売上として加算されていました。入力時にマイナスへ補正し、プラスのままの保存は拒否するようにしました。
2. **売上入力・受注入力で「A second operation was started on this context instance」エラーが出る不具合を修正**
   得意先の確定処理が終わる前に商品コードでEnterを押すと発生していました。
3. **明細入金の「追加（F2）」の有効表示を修正**
   候補を選んでいない状態でも押せるように見えて、押しても何も起きませんでした。候補を選択している間だけ有効になります。
4. **請求締めなどの解除後に一覧が更新されない不具合を修正**
   締め解除のあと、一覧の再読込が行われないことがありました。
5. **納品書の続きページの表示崩れを修正**
   続きページの見出しで括弧が重複したり、ページ表記の位置がずれたりしていました。

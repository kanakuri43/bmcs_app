bmcs_app User Manual

Getting Started: User Manual

This manual explains, step by step, "what screen to use and what to do" for each task. The red frames, numbers and arrows in the screenshots show where to operate. Each number matches the explanation below the image.

The screenshots show the Japanese user interface. To help you find things on screen, each label in the text (menus, buttons, fields, columns) is followed by its Japanese original in parentheses.
The screenshots show sample development data. The customers and amounts are different from your real data.

Workflow

There are two types of customers, and they are billed differently. First check which type your customer is.

Closing-cycle customers (締め取引)Per-transaction billing customers (都度請求; government offices, schools, etc.)
BillingAn invoice is issued once a month, in a batch, on a closing day such as the 20th or the end of the monthAn invoice is issued for each delivery (every few deliveries)
1. Receive an orderOrder Entry (受注入力) (common)
2. Deliver goodsSales Entry (売上入力) (common) / Bulk Delivery Note Issue (納品書一括発行) / Copier Sales CSV Import (コピー機売上CSV取込)
3. Issue an invoiceBilling Closing (請求締め処理)Itemized Invoice Issue (明細請求書発行)
4. Receive a paymentReceipt Entry (入金入力) (automatically applied to the oldest invoices first)Itemized Receipt (明細入金) (choose the sale or invoice to apply it to)
5. Check the balanceCustomer Ledger (得意先元帳) (common)
6. End of monthMonthly Closing (月次締め処理) (common)

First setup (master registration)

Before you start using the system, it is easier if you register the following in this order (a guideline).

  1. Company Information (自社情報) (administrator)
  2. Bank accounts (銀行口座), payment methods (入金方法) and employees (社員) (administrator)
  3. Printer Settings (プリンタ設定) (on each PC)
  4. Products (商品) and customers (得意先) (when registering a customer, you can choose a bank and an employee only if you have registered them first)
  5. As needed, prices and rates for each customer (得意先ごとの単価・掛率) and copiers (コピー機)

Common keys

These keys work the same way on every input screen.

KeyWhat it does
EnterConfirms the input and moves to the next field. In a code field, it looks up the name for that code
Space (in a code field)Opens the search screen (customer, product, slip number, person in charge)
F3New (clears the screen)
F10Save, confirm or issue
F11Print
F8Cancel, discontinue, delete or release (the name differs by screen)
EscCloses a search screen, etc.
If you close a screen without saving, nothing is registered. If you are unsure, press F3 to clear the screen and start over.

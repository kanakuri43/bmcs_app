Register Employees (Administrator)

When to use this
Register the employees who use this system. The registered employee code (社員コード) determines which menus the person can use (permission level).
The employees registered here are also used as the "person in charge (担当者)" on orders and sales.
This screen is for administrators only. It appears in the menu only for employees with permission level 9.

1.How login works (read this first)

This system has no login screen where you enter an ID and password. Instead, you start the system from a desktop shortcut that specifies that person's employee code. The permission level is determined from the employee code used at startup.

  • If you start the system with an employee code that is not in the Employee Master (社員マスタ), the menu is empty (a warning is shown).
  • For a new employee to start using the system, register the employee and prepare a shortcut that starts the system with that person's employee code.

2.Register an employee

From the main menu, open Employee Master (社員マスタ) under Master Management (マスタ管理). Enter the employee code and press Enter (if it is already registered, its details appear; if not, continue entering the details as a new registration).

  1. Employee code (社員コード): Required. This is the number you specify in the startup shortcut.
  2. Employee name and kana (社員名・カナ): The employee name is required. It appears on screens and reports as the person in charge on a slip.
  3. Permission level (権限レベル): The higher the number, the more menus the person can use. 1 = General (day-to-day work), 9 = Administrator (billing release, Employee Master, Company Information, and so on). Each menu has a required level, and only the menus at or below the person's own level are shown.
  4. Press Save (保存) to register. When an employee leaves, deactivate (無効化) them (a deactivated employee can no longer be newly specified as a person in charge. Past slips remain).

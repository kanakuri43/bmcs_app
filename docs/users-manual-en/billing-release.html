Release a Billing Closing (Administrator)

When to use this
Use this to undo a Billing Closing (請求締め処理) that was confirmed by mistake, or when you need to correct a sale after the billing was closed.
When you release it, the sales go back to "not invoiced (未請求)" and can be corrected or canceled.
This screen is for administrators only. It appears on the menu only for employees with permission level 9. It does not appear on the menu of regular employees.

1.Choose the billing date to release

From the main menu, open Billing Release (締め解除処理) under Billing (請求). Enter the Year (年) as 4 digits and choose the Billing Date (請求日). The list of billing data confirmed on that day appears.

  1. Year (年): Enter 4 digits.
  2. Billing Date (請求日): Choose from the dates on which billing was closed in that year.
  3. The billing data that will be released. Everything confirmed on that billing date is included (you cannot choose a customer and release only part of it).
  4. Execute Release (解除実行) (F8): Choose "Yes (はい)" in the confirmation message to release.

If a row has a reason shown in the "Remarks (備考)" column at the right end of the list, the Execute Release button cannot be pressed.

2.When release is not possible

  • For each customer, you can release only the most recent closing. For example, if October was closed after September, release October first and then September (from the newest month back).
  • If even one item cannot be released, none of them is released (a partial release never happens).

3.What to do after releasing

  1. Release with Execute Release (解除実行) (F8) (the sales go back to "not invoiced (未請求)").
  2. In Sales Entry (売上入力), correct or cancel the sales you want to fix.
  3. If needed, also register or correct payments (入金).
  4. Close again with Billing Closing (請求締め処理) (a new billing number is assigned).
Once released, the invoices no longer appear in the list. If you have already printed or sent invoices, replace them with the ones from the new closing.

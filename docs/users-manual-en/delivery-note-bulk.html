Issue Delivery Notes in Bulk

When to use this
Use this to print later, in one go, the delivery notes you did not issue when you registered the sales (the ones where you chose "No (いいえ)").
Only sales whose delivery note has not been issued yet appear in the list, so you can also use it to check for delivery notes you forgot to issue.

1.Open the screen

In the main menu, click Bulk Delivery Note Issue (納品書一括発行) under Orders / Sales (受注・売上). When the screen opens, all sales that have not been issued are listed. The count is shown at the bottom of the screen as "Unissued sales: N (未発行の売上 ○件)".

2.Choose the slips to issue

  1. Slip date (伝票日付): You can narrow down by period (if left empty, all periods are included).
  2. Customer (得意先): You can narrow down to a specific customer only. Enter the code and press Enter, or press Space to search if you do not know it.
  3. Issue (発行) column: Only checked slips are printed. Uncheck the slips you do not want to print.
  4. Select All / Clear All (全選択／全解除): Checks or unchecks all displayed rows at once (after narrowing down, only the displayed rows are affected).
  5. Result (結果): When printing finishes, success or failure is shown here.
  6. Bulk Issue (一括発行): Prints the checked slips (Chapter 3).

3.Issue

Press the Bulk Issue (一括発行) button. After a confirmation message, the checked slips are printed one after another without a preview.

  1. Press Bulk Issue (一括発行) at the bottom right of the screen.
  2. Choose "Yes (はい)" in the confirmation message.
  3. Wait until printing finishes. The message "Delivery note printing is complete (Success: N / Failed: N) (納品書の印刷が完了しました（成功 ○件／失敗 ○件）)" appears at the bottom of the screen.
Slips that print successfully become "Issued (発行済み)", and they no longer appear in the list the next time you open the screen or press "Reload (再読込)". Slips that fail remain unissued, so check the printer and try again.
The printer used for printing is set for each PC in "Printer Settings (プリンタ設定)" under "Master Management (マスタ管理)". If it is not set, the print dialog opens each time you print.
If you want to review a single slip, or check the content before issuing, do not use this screen. Instead, call up the slip in Sales Entry (売上入力) and use Print (印刷) (F11) (a preview opens).

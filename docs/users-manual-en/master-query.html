Run Queries (Administrator)

When to use this
Display the results of a pre-prepared search (query), such as a list of master records, on screen and save it to a CSV file.
Use it when you need a list that the standard screens do not provide, so you can take the data out to Excel or similar.
This screen is for administrators only. It appears in the menu only for employees with permission level 9. Queries are sent directly to the system's database, so only administrators who understand SQL should edit the contents of a query.

1.Select a query and run it

In the main menu, open Master Management (マスタ管理), then open Query Runner (クエリ実行). (On the menu it is labeled "Generic Query".)

  1. Select a query (クエリの選択): Choose the query you want to run.
  2. Conditions (条件): The input fields change depending on the query (this example is a range of customer codes). The values you used last time become the defaults next time.
  3. Run (実行): Shows the results in the list on the right. The number of rows is shown at the bottom of the screen.
  4. Results (結果): Shown with no limit on the number of rows. If the list is wide, use the scroll bar at the bottom to move sideways.
  5. Save CSV (CSV保存): Saves the results currently shown to a CSV file with a header row (a format Excel can open).
  6. Edit query file (クエリファイル編集): Opens the query definition file in Notepad. When you close Notepad, the contents are reloaded.

2.Add or change a query

Queries are written in the query definition file, which is in the system's folder on the PC you are using (if the file does not exist, it is created automatically with a sample). Open it from Edit query file (クエリファイル編集) on the screen, then add or change queries.

  • For each query, write a name, the SQL (the search statement), and the input fields for its conditions.
  • A marker such as #param○○ in the SQL is replaced with the value you enter in the conditions on screen (for a text condition, type the value including the quotation marks).
  • This definition file is separate on each PC. To use the same query on another PC, copy the file. When you replace the system, be careful not to overwrite it.

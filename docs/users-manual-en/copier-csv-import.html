Import Copier Sales (CSV Import)

When to use this
Use this to register sales for each copier machine number in one go, from the copier usage results file (CSV) sent by the manufacturer.
One sale slip is created for each machine number and each closing day. After registering, you can print the delivery notes right away.

0.Preparation needed only once, at the start

PreparationDetails
Register the generic product "COPYCHG"In Product Master (商品マスタ), register one product with product code COPYCHG, product name "Copier usage fee (コピー機利用料)" and tax unit (税種別区分) "Standard rate (通常税率)". If it is missing, a warning appears on the screen and you cannot import.
Register in Copier MasterIn the menu, go to "Master Management (マスタ管理)" → "Copier Master (コピー機マスタ)" and link the CSV's machine number (機番) to a customer (得意先) (enter the machine number and press Enter, enter the customer code, and save). You can link several machine numbers to one customer.

1.Load the CSV file

In the main menu, open Copier Sales CSV Import (コピー機売上CSV取込) under Orders / Sales (受注・売上), press Select File (ファイル選択) and choose the CSV (you can also drag and drop the file onto the screen). After loading, a preview is shown before importing. Nothing has been registered yet at this point.

  1. Select File (ファイル選択): Choose the CSV (files exactly as output by the manufacturer, in Shift-JIS format, can be read).
  2. Rows combined (合算行数): Rows with the same machine number and the same closing day are combined into one and their amounts are totaled. In this example, "110348" is two rows combined, including the basic fee row (¥8,500 + ¥1,500 = ¥10,000).
  3. Status (状態): If it is Ready to import (取込可) (green), the row will be registered. Rows with Error (エラー) (red) will not be registered. You may also see "Already imported (取込済)" and "Not applicable (¥0) (対象外（0円）)".
  4. Reason / Result (理由・結果): The reason for an error is shown here. In this example, machine number "999999" is not registered in Copier Master.
  5. A summary of the number of rows that can be imported, the total amount, and the number of errors.
  6. Run Import (取込実行): Registers only the "Ready to import" rows as sales.

2.Check the status and import

  1. In the preview, check whether there are any error rows. The reasons for errors and what to do about them are in the table below.
  2. Press Run Import (取込実行) and choose "Yes (はい)" in the confirmation message. The "Ready to import" rows are registered one by one, and the Sales No. (売上No.) (or the reason, for a row that failed) is shown in the "Reason / Result (理由・結果)" column.
  3. When it finishes, you are asked "Print the delivery notes? (納品書を印字しますか？)". If you choose "Yes", the delivery notes for the sales just created are printed together without a preview. If you choose "No", the delivery notes remain unissued, and you can issue them later from Bulk Delivery Note Issue (納品書一括発行).
Even if there are error rows, the other rows are still registered. The import is done row by row, separately.

How to read errors and statuses, and what to do

Reason shownWhat to do
Machine number is not registered in Copier Master, or is deactivatedRegister it in Copier Master, then import the same CSV again. Rows that were already registered are excluded as "Already imported (取込済)", so nothing is duplicated.
The period has billing closing or monthly closing doneDo not import it, or ask an administrator to do a Billing Release (締め解除).
The tax-exclusive amount is ¥0 or less (Not applicable)It is not imported. Enter returns and discounts in Sales Entry (売上入力).
Already imported (取込済)The same machine number and closing day can be imported only once. If you want to redo it, cancel the imported sale in Sales Entry, then import again.

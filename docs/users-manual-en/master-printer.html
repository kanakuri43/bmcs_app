Configure Printers

When to use this
Choose which printer to use for each type of document, such as delivery notes and invoices. Once set, you do not have to choose a printer every time you print (for example, "Bulk Delivery Note Issue (納品書一括発行)" prints straight to the printer set here).
This setting is saved for each computer (terminal) you use. It does not affect other computers, so set it on each computer.

1.Choose printers and save

From the main menu, open Printer Settings (プリンタ設定) under Master Management (マスタ管理).

  1. Delivery note (納品書): Delivery notes from Sales Entry, Bulk Delivery Note Issue, and Copier CSV Import.
  2. Invoice (請求書): Invoices from Billing Closing.
  3. Itemized invoice (明細請求書): Invoices from Itemized Invoice Issue.
  4. Accounts receivable balance list (売掛金残高一覧表): The list from Monthly Closing.
  5. Customer ledger (得意先元帳): Printing of the Customer Ledger.
  6. Save (保存): Your changes do not take effect unless you press this.

Click each field to see a list of the printers available on this computer. If you leave it as "(Not set) ((未設定))", the print dialog opens every time you print, and you can choose the printer then.

To save as a PDF, choose Windows' "Microsoft Print to PDF" as the printer (this feature must be enabled on the computer).

操作マニュアル

このマニュアルは、「何をしたいときに、どの画面で、何を操作するか」を順番に説明します。画面の中の赤い枠・番号・矢印が、操作する場所です。番号は、画像の下の説明と対応しています。

画面は開発用データの表示例で、実際の得意先・金額とは異なります。

仕事の流れ

お客様には2種類あり、請求のしかたが違います。最初にどちらのお客様かを確認してください。四角をクリックすると、その画面の説明に移ります。

目次

日々の業務

受注を登録する注文を受けたとき、仮の伝票として記録する 売上を登録する納品したとき、売上にして納品書を出す 納品書をまとめて発行する出していない納品書を後から一括で印刷する コピー機の売上を取り込むメーカーのCSVから機番ごとの売上を登録する 入金を登録する締め取引のお客様の入金を登録する 都度請求の入金を登録する売上・請求書を指定して入金を登録する 得意先の残高を調べる売上・入金・残高を日付順に確認する

請求・締め（月末の作業）

請求を締める締め取引のお客様の月次請求書を作る 明細請求書を発行する都度請求のお客様の請求書をその都度出す 月次締めをする月末の売掛残高を確定する

管理者の作業（権限レベル9）

請求の締めを解除する誤って締めた請求を取り消す 月次締めを解除する誤って締めた月を取り消す 自社情報を登録する請求書に印字する自社の名称・登録番号 社員を登録する使う人と権限レベルを決める メニューを編集するメニューの名前・並び順・使える人 クエリを実行する用意した検索の結果を表示・CSV保存

最初の準備（マスタ登録）

使い始める前に、次の順に登録しておくと進めやすくなります（目安）。

  1. 自社情報（管理者）
  2. 銀行口座・入金方法・社員（管理者）
  3. プリンタ設定（パソコンごと）
  4. 商品、得意先（得意先は、銀行・社員を先に登録しておくと選べます）
  5. 必要に応じて、得意先ごとの単価・掛率、コピー機
得意先を登録する新しい取引先を登録・修正する 商品を登録する新しい商品と単価を登録・修正する 得意先ごとの単価を設定する得意先×商品の特別単価・掛率 コピー機を登録する機番と得意先を結びつける 銀行口座を登録する入金先・請求書の振込先の口座 入金方法を登録する現金・振込などの選択肢を追加・変更 プリンタを設定する帳票ごとのプリンタを決める

共通のキー操作

どの入力画面でも同じ操作でできます。

キーできること
Enter入力を確定して次の欄へ進む。コード欄ならそのコードの名称を引く
Space（コード欄で）検索画面を開く（得意先・商品・伝票番号・担当者）
F3新規（画面を空にする）
F10保存・確定・発行
F11印刷
F8取消・中止・削除・解除（画面によって名前が違います）
Esc検索画面などを閉じる
入力を保存せずに画面を閉じても、データは登録されません。迷ったら F3 で空に戻して、最初からやり直せます。

メニューを編集する（管理者）

こんなときに使います
メインメニューの名前・並び順・使える人（権限レベル）を変えたいときに使います。
たとえば「この機能は、一般社員にも使わせたくない（管理者だけにしたい）」というときに、必要な権限レベルを9にします。
管理者専用の画面です。権限レベル9の社員にだけメニューに表示されます。変更は、メインメニューを次に起動したときから反映されます。

1.項目を選んで、直して、保存する

メインメニューの「マスタ管理」の中の「メニューマスタ管理」を開きます。左の一覧から直したい項目をクリックすると、右の「編集」に内容が出ます。

  1. メニューの一覧：分類（受注・売上、請求、…）と、その中の機能が並びます。「必要権限」は、その機能を使うのに必要な権限レベルです。
  2. 直したい項目をクリックして選びます。
  3. 表示名：メインメニューに出る名前。
  4. 表示順：並び順（小さい数字が上）。
  5. 必要権限レベル（機能のみ）：1＝一般、9＝管理者専用。本人の権限レベルがこの数字以上の社員にだけ、その機能が表示されます。
  6. 初期状態で開く（分類のみ）：メインメニューを開いたときに、その分類を開いた状態にするかどうか。
  7. 保存：押さないと反映されません。

2.この画面でできないこと

  • 項目の追加・削除、画面キーの変更、親子関係（どの分類に入れるか）の変更はできません。これらは、システムの設定ファイル（SQL）を直接直す作業で、開発担当者に依頼します。
  • メニューの設定は、システムのバージョンアップなどで初期値に戻ることがあります。大きく変更したときは、変更内容を控えておいてください。
